# The Symbiosis

The Symbiosis is an evolving proposal for a distributed civilizational system in which humans remain the source of legitimacy and direction while artificial agents extend collective memory, reasoning, and coordination.

Its North Star is:

> **Keep humans, truth and peace inside the future.**

## Manifest

The foundational public text currently preserved in this repository is:

**[The Human–AI Symbiosis Manifest](./MANIFEST.md)**

The Manifest describes the North Star, constitutional principles, Goal Chain, Shared Semantics Layer, Canon, Anti-Capture Layer, Ledger, Global Harnessing, Distributed Agentic Power, and the relationship among them.

## Repository status

This repository is intentionally minimal at this stage.

The first artifact committed here is the Manifest. Additional primary materials may be added as they become ready for public release. Changes and revisions remain visible through the repository history.
